# 可靠性修复报告（1104 审查 · V1.7）

> 对应《NoteFly 1104 版源码审查与蚁小二差距分析》的第一批（P0 全部）+ P2 + 最小安全修复。
> 本批不扩展平台数量、不重写界面。

## 交付清单

### P0-1 一键排版改坏原文（已修复）
- **根因**：`lib/text-tools.js` 两层 `protectSegments()` 各自从 0 生成占位符，第二层还原时把第一层占位符当成自己的，行内代码/公式被替换成链接；代码块重拼后全局 `\n{3,}` 压缩改变代码语义。
- **修复**：同一次排版内所有保护层共享一个 store（`protectSegments(text, patterns, sharedStore)`）；新增 `restoreAll()` 循环还原嵌套占位符；全局空行压缩改为按 fence 切分后只作用于普通文本块（`compressBlankLines`）。
- **回归**：`tests/text-tools-p0.test.js` 5 条复现用例（行内代码＋链接 / 公式＋链接 / HTML＋链接 / 代码块多行字符串 / 幂等），修复前 5/5 失败，修复后全过；原 35 条 text-tools 用例不受影响。

### P0-2 数据迁移覆盖目标记录（已修复）
- **根因**：`lib/data-dir.js` 迁移时文件直接覆盖、目录存在则跳过 —— 目标 store.json 被覆盖且源素材漏迁。
- **修复**：非空目标**拒绝迁入**并返回冲突清单（一个字节不动）；关键数据（store/config）复制失败整体回滚；素材目录复制失败也回滚（避免稿件图片错配）；接口返回 409。
- **回归**：`tests/data-dir-p0.test.js` 4 条；原 `data-dir.test.js` 中锁定旧「跳过」行为的用例已按新契约改写。

### P0-3 任务超时不取消 / 并行执行 / 迟到结果覆盖（已修复）
- **修复**（`server.js` + `engines/rpa.js`）：
  - 执行登记 `activeRuns`（taskId → runToken）：超时删除登记，迟到结果识别后作废并记 `stale_result_discarded`；
  - 队列保留底层执行引用：超时后**等 RPA 真正落定**才放行下一任务（宽限期超时强制 `closeAll()`），全程并发 = 1；
  - 超时任务进 **unknown（待核验）** 而非 failed —— 不再诱导重发；未落定目标翻成 unknown；
  - `rpa.publish` 新增 `opts.onProgress` 逐目标回调，服务端每确定一个平台结果立即落盘（第二平台卡死不丢第一阶段记录）。
- **回归**：`tests/server-p0.test.js` 4 条（超时待核验 / 不并行 / 迟到作废 / 逐目标持久化），假 rpa 记录并发。

### P0-4 accepted/reviewing 可重复提交（已修复）
- **修复**：统一 `NO_RESUBMIT` 拦截集（success/published/accepted/reviewing/submitting/unknown），三个入口（整任务提交 / 单目标提交 / 单目标重填）共用；`submitting` 状态先落盘再调平台。
- **回归**：`tests/server-p0.test.js` 后 2 条（accepted/reviewing 409 拦截；failed 放行一次后二次拦截，底层只调一次）。

### P2 AI endpoint 重复拼接（已修复）
- `lib/ai.js`：baseUrl 已是完整 endpoint（`…/chat/completions`）时不再追加路径。回归 `tests/ai-endpoint.test.js`（拦截出站请求验证）。

### 安全最小修复
- `server.js` `app.listen` 显式绑定 `127.0.0.1`，本地无鉴权接口不再监听局域网网卡。

### 排版可撤销
- 编辑器应用「一键排版 / 去 AI 味」前自动保存原文快照（栈深 10），工具条出现「撤销排版」按钮，一键恢复。
